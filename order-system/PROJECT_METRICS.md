## 🏗️ Архитектурные решения

### Основной паттерн

```
PARSER → CATALOG → EXCEL → USER INPUT → ORDER → EXPORT → EMAIL
```

### Разделение ответственности

| Модуль | Ответственность |
|--------|-----------------|
| `parsers/` | Извлечение данных с vitex.pro |
| `export/` | Экспорт и форматирование |
| `orders/` | Модели данных |
| `utils/` | Хранилище и поиск |

### Форматы данных

```python
# На выходе парсера (позиция)
{
    "Kategoriya": "...",
    "Naimenovanie RU": "...",
    "Naimenovanie EN": "...",
    "Opisanie": "...",
    "Fasovka": "...",
    "Ssylka": "..."
}

# В Excel (строка с номером)
Номер | Русское наименование | ... | Количество | URL

# В заявке (OrderItem)
product_name, category, quantity, unit, price, product_url, notes
```

## 🚀 Развертывание

### Требования к окружению

- Python 3.8+
- pip (Python пакетный менеджер)
- Internet connection (для парсинга)
- SMTP сервер (для email)

### Установка

```bash
git clone <repo>
cd order-system
pip install -r requirements.txt
python excel_workflow_example.py
```

### Конфигурация

- Email: Установить переменные в `EmailFormatter`
- Parser: Установить URLs в `parsers/config.py` (опционально)

## 🎯 Успешные кейсы использования

### Кейс 1: Магазин красок

```
1. Парсим каталог витекс.про (100+ товаров)
2. Экспортируем в Excel
3. Продавец заполняет количества
4. Система создает заявку
5. Письмо автоматически генерируется
6. Email отправляется менеджеру
```

### Кейс 2: Оптовая компания

```
1. Каждый клиент получает Excel с каталогом
2. Заполняет количества
3. Отправляет файл
4. Система обрабатывает автоматически
5. Заявка сохраняется в системе
```

### Кейс 3: B2B закупки

```
1. API экспортирует каталог
2. Система CRM получает товары
3. Автоматическое заполнение каталога
4. Заявка из CRM → в нашу систему
5. Двусторонняя синхронизация
```
